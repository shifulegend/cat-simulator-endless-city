Credits

Endless City Cat is MIT-licensed. It uses (or is designed to use) the following free / open-source tools and assets. Add each new dependency or asset here as it is introduced.

Libraries & Frameworks

  • Three.js — 3D rendering engine. (MIT License)
  • Vite — build tool / dev server. (MIT License)
  • Rapier — physics engine for collision detection and movement realism. (Apache-2.0)
  • postprocessing (pmndrs) — bloom, SSAO/GTAO, depth of field, ACES tone mapping. (Zlib License)
  • GSAP — UI and camera tweening. (MIT License)
  • lil-gui — runtime debug panel (dev-only). (MIT License)
  • stats.js — FPS/frame-time overlay (dev-only). (MIT License)
  • Draco — glTF geometry compression. (Apache-2.0)
  • KTX2 / Basis Universal — GPU texture compression. (Apache-2.0)

Backend & Database

  • Supabase — open-source Postgres backend used for leaderboards/save data. Access is controlled via Row Level Security policies using only the public anon key in client code. (Apache-2.0, self-hostable)

3D Models & Textures

Hero-quality assets (the cat, foreground buildings, foliage) are sourced from higher-fidelity libraries first; Poly Haven / ambientCG are used only as a fallback for generic background surfaces where budget or licensing rules out better options.

  • Fab (formerly Quixel Megascans) — photogrammetry-scanned rock, bark, ground, and foliage textures/models, closer to AAA fidelity. (license varies per asset — check before vendoring; free assets preferred)
  • Sketchfab — downloadable, hand-modeled or scanned hero-quality models (credit individual authors per model used). (CC0 / CC-BY, varies per model)
  • Poly Haven — HDRIs and generic PBR textures for background/non-hero surfaces. (CC0)
  • ambientCG — generic PBR material textures for background/non-hero surfaces. (CC0)

Audio

  • Freesound.org — CC0/CC-BY sound effects (credit individual authors per clip used). (CC0 / CC-BY, varies per clip)
  • Web Audio API — procedural sound synthesis (browser-native, no license required).

Animation

  • Mixamo — free character animation rigs (if adopted). (Adobe free license — check terms of use)
